# Sistema de Simulados Acadêmicos

Projeto de apoio pedagógico para as disciplinas de Lógica Computacional
e Ergonomia de Sistemas Computacionais e IHC.

## Arquivos principais

-   `PROMPT-INICIAL-CLOUD-CODE.md` --- instruções iniciais para o Cloud
    Code.
-   `PRD-Sistema-de-Simulados.md` --- escopo, regras, arquitetura
    conceitual e decisões do produto.
-   `BANCO-DE-QUESTOES.md` --- banco inicial com 20 questões de cada
    disciplina e gabarito.

## Fonte das questões

O banco foi construído a partir das provas N1 e dos simulados fornecidos
pelo professor. A regra é não inserir conteúdo fora do que foi
efetivamente trabalhado/avaliado.

## Stack

-   React + Vite
-   Supabase/PostgreSQL
-   Hostinger
-   GitHub
-   Cloud Code

## Regra importante

O aluno não usa Supabase Auth no MVP. A identificação é simplificada
para manter a experiência rápida.

## Estado do projeto

Documentação e banco inicial preparados para a etapa de arquitetura e
validação no Cloud Code.
